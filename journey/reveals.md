# reveals (Paradev = ~/Desktop/superset)
- apps/desktop/src/renderer/index.html: empty shell + React (index.tsx), CSP meta, theme-boot before body. Stack: Electron + electron-vite + React 19 + Tailwind 4 + xterm 6.1 beta + lucide-react.
- docs/screenshots/new-workspace-from-plugin.png: layout we copied (New Workspace button, PROJECTS section, composer home with chips).
- apps/desktop/src/renderer/lib/terminal/terminal-addons.ts loadAddons(): WebGL loaded in rAF after open (post-open measure race), per-terminal fallback to DOM on context loss + refresh, never latch failure; browsers cap live WebGL contexts.
- packages/pty-daemon (Server/Server.ts listen(), SessionStore/SessionStore.ts): same shape as corrald. Unix socket, unlink stale, chmod 600 after listen ("socket file IS the auth boundary"; we umask first, so we're tighter). Replay = ~64KB circular byte chunks (ours 2MB): just enough to redraw, scrollback is xterm's job. Framing = 4-byte length prefix + JSON (ours NDJSON). Extras we lack: session handoff to a new daemon (upgrade without killing agents), respawn (apps/desktop/src/main/lib/host-service-respawn.ts), process-tree kill.
- Scale check 2026-11-12: corral 1.2k lines vs paradev ~871k (desktop 415k, pty-daemon 3.9k).
