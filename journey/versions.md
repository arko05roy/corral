# versions
- v0: cp -r repo per task, `claude -p` headless, logs to file. Real repo: 4.9s + 1.2GB per pen, symlinks broken.
- v1: `git worktree add -b corral/<slug>` per task. 1.6s + 287MB per pen (files only), shared .git, symlinks intact.
- v2: Electron app. Interactive claude in a node-pty PTY per pen, xterm.js panel per pen, IPC carries bytes both ways. Path there: pipes -> claude saw isatty()=false and went headless; node-pty -> raw escape codes in <pre>; xterm.js -> works.
- v3: React + Vite renderer, Paradev-style layout (sidebar repos/threads, composer home, files panel w/ Changes/Files tabs) in Corral theme (cream paper, cobalt ink, amber lamps, etched hills). Preload bridge replaces nodeIntegration. Old pens read from `git worktree list` (git = the pen database), resumed with `claude --continue`. Terminal sized to panel via fit addon → pty.resize → SIGWINCH. Bug found on the way: fit addon ignores parent padding under border-box → overshot cols/rows; fixed with inset.
- v3.1: agent status. Claude hooks (UserPromptSubmit/PreToolUse → working, Stop/Notification → waiting) injected per spawn via `--settings`; hook finds its thread through inherited env CORRAL_THREAD. Channel v0 = hook writes ~/.corral/status/<id>.json, Corral fs.watches. Stress test: `cat >` gave 8/10 torn reads; temp + `mv` (atomic rename) → 0 in 1,500 writes. fs.watch coalesces (300 writes → ~10 events): fine for latest-state-wins.
- v4: corrald daemon (src/daemon.ts) owns PTYs + hooks; Electron app is a client over a Unix socket (~/.corral/corrald.sock, owner-only via umask+chmod), NDJSON both ways, reqId request/response. Why: Corral quitting closed the PTY master → kernel SIGHUP → claude died. Re-attach on launch via `list`. Bite: re-attached terminal started mid-stream (tick 10) → per-agent replay buffer (last 2MB, trimmed to a newline), sent before the reply on the same ordered socket.
- v4.2: kill-thread. UI ■ button → kill RPC → daemon sends SIGHUP (polite "terminal hung up"), SIGKILL after 3s if ignored; guard skips SIGKILL if onExit already removed the agent. Pen stays on disk; clicking a dead thread resumes with --continue (new agent id, same pen). Verified over the socket: exited in 901ms on SIGHUP alone, double-kill → "no such agent", resume after kill → alive/waiting.
- v4.3: pen lifecycle as 3 separate actions (copied from Paradev split): Merge (commit if dirty → local git merge into repo current branch, pen kept; conflict → merge --abort), Open PR (commit → push → gh pr create, link opens in real browser via setWindowOpenHandler, never an Electron window w/ preload), Delete (refuses dirty/unmerged w/o second click; Paradev fast path: rename → worktree prune → detached rm -rf). User confirmed in app. Also: agents spawn at the UI's measured cols×rows (Paradev createOrAttach pattern) + 1-col wiggle redraw when born at a guessed size; bug was new threads rendering as confetti (100×30 frames landing on a re-fit grid). Size fix NOT yet verified (needs daemon restart).
- v4.4: daemon version handshake. Problem: corrald outlives the app, so it also outlives code edits (version skew): the v4.3 size fix sat unused in a stale daemon. Version = sha256 of daemon.ts+pens.ts+version.ts (auto, not a hand-bumped constant). Daemon hashes once at boot, answers `hello` {version,pid,agents}. App probes on a throwaway connection BEFORE any window exists; mismatch or no reply (pre-handshake) → SIGTERM (pid from hello, else `lsof -t` on the socket) → wait for socket to die → auto-start fresh. First try was a "Restart now / Later" banner: its button was dead because it floated over the topbar drag region (Electron app-region: drag eats clicks regardless of z-index). User then chose silent auto-restart: "a user shouldn't be seeing this." Verified live: replaced pid 61772 → 78993, log shows version 32de8f63541e.
- v5: Corral becomes "the one window" (user's vision: replace Ghostty + VS Code). (1) File viewer: CodeMirror 6 (chosen over Monaco: themeable to Corral, not VS Code's look), read-only, ⌘F, lazy per-language grammars, in a blurred floating modal with a file tree (user's sketch). (2) Diff vs MERGE-BASE (fork point): user first picked "real repo now"; demo showed it invents phantom deletions when main moves. Changes list = everything differing from merge-base (fixes "blind after commit" debt). Side-by-side MergeView, wrapped, collapsed context. (3) Real file logos: vscode-icons subset (142 icons, 262KB) extracted at build time (scripts/build-icons.mjs). (4) Git command center: whitelisted recipes in src/app/git.ts (command pattern: renderer names an action, never sends git args), grouped panel, generic action dialog, AI commit message via `claude -p`, branch picker (datalist hid "main": it filters by typed text). Async git (sync exec froze Electron's main process during pushes), GIT_TERMINAL_PROMPT=0. integrateAndPush: if target moved, rebase local-only commits (drops squash duplicates by patch) else merge. Auto-fetch ≤1/min. (5) PR window (blurred): list/detail/checks/files/comments, merge (squash/merge/rebase), close/ready/reopen/comment via gh. NOT gh's --delete-branch (checks out main in the pen → breaks); we push --delete. Comments rendered via marked + DOMPurify (untrusted HTML in a window with the git bridge); will-navigate blocked; CSP img-src allows https. (6) Merged state: "Merged · Clean up" asks GitHub (not local git) → ff local main → delete thread. (7) Short branch names ("banchor-live-link"), task stored as git branch description. (8) Repo setup: git init (+ default .gitignore) and Create on GitHub (gh repo create).
